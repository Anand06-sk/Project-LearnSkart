Important Topics

EE3302 – Digital Logic Circuits

UNIT 1 – Number Systems & Logic Families

  • Number system conversions (Binary, Octal, Hex → Decimal)
  • 1's & 2's complement (subtraction problems)
  • Hamming code (even/odd parity, error detection & correction)
  • TTL logic (Inverter, NAND, Totem pole, tristate output)
  • CMOS logic (NOR gate, advantages, CMOS technology basics)
  • ECL logic family (concept & wired OR operation)
  • Boolean function forms (Canonical SOP)
  • Logic minimization using Quine–McCluskey method

UNIT 2 – Combinational Circuits

  • K-map simplification (with/without don't care conditions)
  • SOP & POS forms (conversion + implementation)
  • Implementation using NAND gates (very important)
  • Multiplexer-based realization of Boolean functions
  • Half adder, Full adder & Full subtractor design
  • Code converters & Priority encoders
  • XOR implementation using NAND gates
  • Logic design using multiplexers

UNIT 3 – Synchronous Sequential Circuits

  • Flip-flops (JK, D, Master-Slave JK) – operation
  • Triggering methods (level & edge triggering)
  • State table & State diagram construction
  • Sequential circuit analysis & design
  • Synchronous counters (MOD counters design)
  • Sequence generators (given state transitions)

UNIT 4 – Asynchronous Circuits & PLDs

  • Asynchronous sequential circuit design (flow table & state diagram)
  • Hazards (static, dynamic) & elimination methods
  • Memory devices (PROM, EPROM, EEPROM)
  • Programmable Logic Devices (PAL, PLA)
  • Transition table & primitive flow table

UNIT 5 – VHDL

  • VHDL modeling styles (Behavioral, Structural, Dataflow)
  • VHDL code for:
  • Full Adder
  • Flip-flops (SR, JK)
  • Counters (MOD, binary)
  • Multiplexer / Demultiplexer
  • Testbench writing
  • Digital system design flow
  • Code converters & Array multiplier design using VHDL
  • Built-in operators in VHDL
